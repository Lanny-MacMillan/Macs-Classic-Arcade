# Missile Command

Classic arcade defense game where you protect cities from incoming missile attacks.

## How to Play

- Click anywhere on the screen to launch defensive missiles
- Your missiles will intercept incoming threats when they reach the click location
- Protect your cities and batteries from destruction
- Each wave gets progressively harder with more missiles
- You earn bonus points for surviving cities at the end of each wave

## Game Controls

- **Mouse Click**: Launch defensive missile to target location
- **Restart Button**: Start a new game
- **Back to Arcade**: Return to the main menu

## Scoring

- 25 points for each enemy missile destroyed
- 100 points per surviving city at wave end
- Bonus ammo awarded between waves

## Strategy

- Aim ahead of incoming missiles to maximize explosion overlap
- Protect cities and batteries equally
- Use ammo wisely as it's limited per wave
- Create chain reactions by detonating multiple missiles in one explosion

## Features

- Progressive difficulty system
- Wave-based gameplay
- Limited ammunition management
- Multiple cities and battery positions to defend
- Explosion collision detection
- Score tracking and wave progression
