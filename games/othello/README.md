# Othello (Reversi)

Classic Othello strategy game built with vanilla JavaScript.

## Game Modes

- **2 Players**: Play against a friend locally
- **vs Computer**: Challenge the AI with three difficulty levels

## Difficulty Levels

- **Easy**: Computer makes random valid moves
- **Medium**: Computer maximizes piece flips each turn
- **Hard**: Strategic AI that prioritizes corners, avoids danger zones, and maximizes flips

## How to Play

- Select your game mode and difficulty (if playing vs computer)
- Click on a valid cell to place your piece
- Capture opponent pieces by surrounding them
- Valid moves are highlighted in lighter green
- Game ends when no valid moves remain
- Player with the most pieces wins

## Rules

- Black starts first
- You must flip at least one opponent piece with each move
- Pieces flip in all 8 directions
- If you have no valid moves, your turn is skipped
- Game ends when neither player can move

## Controls

- Click cells to place pieces
- New Game button to restart and select mode again
- Back to Arcade to return to main menu
