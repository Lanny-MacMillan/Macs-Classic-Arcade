# Memory Card Game

A classic memory matching game built with vanilla JavaScript.

## How to Play

1. Click on any card to flip it over
2. Click on a second card to try and find its match
3. If the cards match, they stay face up
4. If they don't match, they flip back over
5. Match all pairs to win the game

## Features

- 4x4 grid (8 pairs)
- Move counter
- Pairs matched tracker
- Win detection
- Reset game functionality
- Back to arcade navigation

## Tech Stack

- Vanilla JavaScript (ES6+)
- HTML5
- CSS3

## Running the Game

Simply open `index.html` in a modern web browser.

## Arcade Integration

The game wraps its logic in `initMemoryGame(container)` function for easy integration with the arcade system.
