# Breakout

A classic brick-breaking arcade game built with vanilla JavaScript and HTML5 Canvas.

## How to Play

- Use arrow keys or move your mouse to control the paddle
- Bounce the ball off the paddle to break bricks
- Break all bricks to win
- Don't let the ball fall off the bottom

## Controls

- **Arrow Keys** or **A/D keys**: Move paddle left/right
- **Mouse**: Move paddle to follow cursor

## Scoring

- Each brick destroyed: 10 points
- Win condition: Break all 50 bricks (500 points)

## Features

- Smooth ball physics with angle-based paddle bounces
- 5 rows of colorful bricks
- Real-time score tracking
- Win and lose states
- Easy restart functionality

## Tech Stack

- Vanilla JavaScript (ES6+)
- HTML5 Canvas
- CSS3
