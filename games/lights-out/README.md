# Lights Out

Classic puzzle game where the goal is to turn off all the lights.

## How to Play

- Click any light to toggle it and its adjacent neighbors (up, down, left, right)
- Turn off all lights to win
- Try to win in the fewest moves possible

## Rules

- Each click toggles 5 cells (the clicked cell plus 4 neighbors)
- Corner cells have 3 toggles, edge cells have 4 toggles, center cells have 5 toggles
- Every puzzle is solvable

## Controls

- Mouse: Click cells to toggle
- Reset: Start a new puzzle
- Back to Arcade: Return to game selection
