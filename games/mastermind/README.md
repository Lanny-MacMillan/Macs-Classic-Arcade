# Mastermind

A classic code-breaking puzzle game where you must guess a hidden sequence of colors.

## How to Play

- The computer generates a secret code of 4 colors
- Select colors from the palette to build your guess
- Submit your guess to receive feedback
- Black pegs indicate correct color in correct position
- White pegs indicate correct color in wrong position
- You have 10 attempts to crack the code

## Features

- 6 different colors to choose from
- Visual feedback system
- Guess history tracking
- Responsive design

## Controls

- Click colors to add them to your guess
- Click Submit when all 4 slots are filled
- Click Clear to reset current guess
- Click Restart to start a new game
