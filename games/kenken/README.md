# KenKen

A math-based logic puzzle game where you fill a grid with numbers following mathematical constraints.

## How to Play

- Fill each row and column with unique numbers from 1 to grid size
- Each outlined cage must produce the target number using the specified operation
- Click cells to enter numbers or use arrow keys to navigate
- Check your solution when complete

## Features

- Multiple puzzle difficulties
- Input validation
- Visual feedback for correct/incorrect answers
- Keyboard navigation support
