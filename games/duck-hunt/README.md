# Duck Hunt

A classic shooting gallery game where you hunt flying ducks across the screen.

## How to Play

- Click on the ducks as they fly across the screen
- You have 10 shots per round
- Hit a duck: +100 points
- Miss a shot: -10 points
- Try to get the highest score possible

## Controls

- Mouse Click: Shoot

## Features

- Moving duck targets with varied flight patterns
- Limited ammunition system
- Score tracking with hit/miss penalties
- Smooth animations and visual feedback

## Tech Stack

- Vanilla JavaScript
- HTML5 Canvas
- CSS3
