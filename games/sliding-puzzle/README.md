# Sliding Puzzle

Classic 15-puzzle game built with vanilla JavaScript.

## How to Play

1. Click tiles adjacent to the empty space to slide them
2. Arrange tiles in order from 1 to 15
3. Track your moves and try to solve it in as few moves as possible

## Rules

- Only tiles next to the empty space can move
- Tiles slide into the empty space when clicked
- Goal: arrange all tiles in numerical order (1-15)

## Features

- Solvable puzzle generation
- Move counter
- Reset functionality
- Win detection
- Responsive design

## Implementation

- Pure vanilla JavaScript
- No external dependencies
- Grid-based layout using CSS Grid
- Inversion counting for solvability

## Run Instructions

Open `index.html` in any modern web browser.
