# Aim Trainer

A fast-paced reaction game that tests your mouse accuracy and reaction time. Click targets as quickly and accurately as possible within 30 seconds.

## How to Play

1. Click "Start Game" to begin
2. Targets will appear randomly on the screen
3. Click each target as fast as you can
4. Each target disappears after 1.5 seconds if not clicked
5. Missing clicks reduces your accuracy
6. Game ends after 30 seconds

## Scoring

- Each successful hit: 10 points
- Accuracy: Successful hits / Total clicks
- Reaction Time: Time between target appearance and your click

## Controls

- Mouse click on targets

## Features

- Random target spawning
- Real-time accuracy tracking
- Average reaction time calculation
- 30-second timed gameplay
- Score tracking
- Game statistics display

## Tech Stack

- Vanilla JavaScript (ES6+)
- HTML5
- CSS3

## Installation

Simply open `index.html` in a web browser. No build process or dependencies required.
