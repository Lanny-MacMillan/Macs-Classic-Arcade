# Reaction Timer

Test your reflexes with this simple reaction time game.

## How to Play

1. Click "Start" to begin
2. Wait for the screen to turn from red to green
3. Click as fast as possible when it turns green
4. Don't click too early or you'll fail

## Features

- Random delay between 2-5 seconds
- Accurate timing measurement using Date.now()
- Best score tracking (saved in localStorage)
- Early click detection

## Controls

- Mouse click to interact
- Back to Arcade button to return to main menu

## Game States

- **Idle**: Start screen with instructions
- **Waiting**: Red screen - don't click yet
- **Ready**: Green screen - click now!
- **Result**: Shows your reaction time or failure message
