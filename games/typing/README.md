# Typing Speed Test

Test your typing speed and accuracy with this classic typing game.

## How to Play

1. A random sentence will appear on the screen
2. Start typing in the input field
3. The timer starts automatically on your first keystroke
4. Type the displayed text as accurately and quickly as possible
5. The game ends when you complete the entire text

## Features

- Real-time WPM (Words Per Minute) calculation
- Accuracy tracking
- Visual feedback for correct/incorrect characters
- Multiple test sentences for variety
- Reset button to try again

## Scoring

- **WPM**: Calculated based on characters typed divided by 5 (standard word length) per minute
- **Accuracy**: Percentage of correctly typed characters
- **Time**: Total time taken to complete the test

## Tips

- Focus on accuracy first, speed will come with practice
- Keep your eyes on the text display, not your keyboard
- Maintain a steady rhythm rather than rushing
- Use all fingers for optimal typing efficiency

Good luck and have fun improving your typing skills!
