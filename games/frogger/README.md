# Frogger

Classic lane-crossing arcade game built with vanilla JavaScript and HTML5 Canvas.

## How to Play

- Use **Arrow Keys** or **WASD** to move your frog up, down, left, and right
- Navigate through lanes of traffic to reach the goal at the top
- Avoid getting hit by moving obstacles (cars)
- Each successful crossing increases the difficulty level

## Game Rules

- You start with 3 lives
- Collision with any obstacle costs you one life
- Reaching the goal zone advances you to the next level
- Game ends when you run out of lives
- Higher levels feature faster and more obstacles

## Features

- Grid-based movement system
- Multiple lanes with varying speeds
- Progressive difficulty scaling
- Lives and level tracking
- Collision detection
- Win/lose conditions

## Controls

- **↑ / W** Move Up
- **↓ / S** Move Down
- **← / A** Move Left
- **→ / D** Move Right

- Vanilla JavaScript
- HTML5 Canvas
- CSS3
