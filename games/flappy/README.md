# Flappy Bird

A minimal side-scrolling game where you navigate a bird through pipes.

## How to Play

- Press **SPACE** or **Click** to make the bird flap and fly upward
- Avoid hitting the pipes
- Pass through pipes to increase your score
- Game ends on collision

## Features

- Physics-based movement with gravity
- Procedurally generated obstacles
- Score tracking
- Game over and restart functionality

## Controls

- **SPACE** or **Mouse Click**: Flap/Jump
- **Start Game**: Begin playing
- **Play Again**: Restart after game over
- **Back to Arcade**: Return to main menu
