# Avoider

A fast-paced arcade game where you dodge falling obstacles for as long as possible.

## How to Play

- Use **Arrow Keys** or **A/D** to move left and right
- Avoid the falling obstacles
- The game gets progressively faster as you survive longer
- Your score increases with every frame you survive

## Game Mechanics

- Player speed: responsive movement at 7px per frame
- Obstacles spawn randomly from the top
- Fall speed increases over time
- Spawn rate increases over time
- Collision detection ends the game

## Features

- Progressive difficulty increase
- Real-time score tracking
- Speed multiplier display
- Smooth canvas rendering
- Responsive controls
