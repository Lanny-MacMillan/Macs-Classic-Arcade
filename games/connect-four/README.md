# Connect Four

A classic two-player strategy game built with vanilla JavaScript. Play against a friend or challenge the computer.

## How to Play

- Players alternate turns dropping colored discs into a 7-column, 6-row grid
- Pieces fall to the lowest available space in the selected column
- First player to get four of their discs in a row (horizontal, vertical, or diagonal) wins
- If the board fills up with no winner, the game is a draw

## Game Modes

**2 Players**: Play against a friend on the same device

**vs Computer**: Challenge the AI with three difficulty levels:

- Easy: Random moves
- Medium: Blocks your wins and tries to win
- Hard: Strategic play with position evaluation

## Features

- Two-player local multiplayer
- AI opponent with multiple difficulty levels
- Gravity mechanics for piece placement
- Win detection in all directions
- Visual feedback with colored discs
- Reset functionality
- Responsive design

## Controls

- Click on any column to drop your piece
- Click "New Game" to return to mode selection
- Click "Back to Arcade" to return to the main menu
