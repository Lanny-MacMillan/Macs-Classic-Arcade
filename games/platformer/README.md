# Platformer

A jump-based platformer game with 5 progressively challenging levels, hazards, and gravity physics.

## How to Play

- Use Arrow Keys or WASD to move left and right
- Press SPACE or UP arrow to jump
- Collect all the gold coins in each level
- Touch the green switch to advance to the next level
- Avoid red spike hazards
- Don't fall off the bottom of the screen

## Features

- 5 levels with increasing difficulty
- Responsive movement controls
- Gravity and jump physics
- Platform collision detection
- Deadly spike hazards
- Level progression system with switches
- Score tracking

## Technical Details

Built with vanilla JavaScript using HTML5 Canvas for rendering. Features physics-based movement, collision detection for platforms and hazards, and a level progression system.
