# Nonogram

A classic logic puzzle game where you reveal a hidden picture by filling in cells based on number clues.

## How to Play

- Each row and column has number clues that indicate groups of consecutive filled cells
- Left-click a cell to fill it (black)
- Right-click a cell to mark it as empty (X)
- Use the clues to deduce which cells should be filled
- Click "Check Solution" to validate your answer
- Click "New Puzzle" to try a different puzzle

## Controls

- **Left Click**: Fill cell
- **Right Click**: Mark cell as empty
- **Check Solution**: Validate your answer
- **Clear Grid**: Reset the puzzle
- **New Puzzle**: Load a different puzzle

## Example

If a row shows "3 1", it means there's a group of 3 filled cells, then at least one empty cell, then 1 filled cell.
