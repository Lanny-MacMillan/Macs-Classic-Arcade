# Sudoku

A clean, playable Sudoku game built with vanilla JavaScript.

## Features

- 9x9 grid with visual 3x3 subgrid separation
- 3 pre-generated puzzles
- Click to select cells
- Keyboard input (1-9, Backspace/Delete to clear)
- Fixed cells cannot be edited
- Real-time validation highlighting
- Win detection
- Reset current puzzle
- Switch to new puzzle
- Back to Arcade integration

## How to Play

1. Click on an empty cell to select it
2. Type a number (1-9) to fill the cell
3. Press Backspace or Delete to clear a cell
4. Each row, column, and 3x3 box must contain numbers 1-9 without repetition
5. Invalid placements are highlighted in red
6. Complete the puzzle to win

## Controls

- Mouse click to select cells
- Keyboard 1-9 for input
- Backspace/Delete to clear
- Reset Game button to restart current puzzle
- New Puzzle button to load next puzzle
- Back to Arcade button to return

## Tech Stack

- Vanilla JavaScript (ES6+)
- HTML5
- CSS3
- No frameworks or libraries
